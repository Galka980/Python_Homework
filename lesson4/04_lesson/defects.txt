Баг-репорты для класса StringUtils
==================================

1. Баг №001: Метод capitalize() может вызывать IndexError
   Описание: При передаче пустой строки в метод capitalize() возникает IndexError
   Шаги воспроизведения:
     1. Создать экземпляр StringUtils
     2. Вызвать utils.capitalize("")
   Ожидаемый результат: Возвращается пустая строка
   Фактический результат: IndexError: string index out of range
   Приоритет: Высокий
   Исправлено: Да (добавлена проверка if not string)

2. Баг №002: Метод trim() удаляет только начальные пробелы
   Описание: Согласно документации, метод должен удалять пробелы в начале,
             но пользователь может ожидать удаление всех пробелов
   Шаги воспроизведения:
     1. Вызвать utils.trim("  test  ")
   Ожидаемый результат: "test"
   Фактический результат: "test  " (пробелы в конце остаются)
   Приоритет: Низкий (соответствует документации)
   Исправлено: Нет (работает по спецификации)

3. Баг №003: Метод contains() с пустым символом
   Описание: При поиске пустого символа метод всегда возвращает True
   Шаги воспроизведения:
     1. Вызвать utils.contains("anything", "")
   Ожидаемый результат: False или ValueError
   Фактический результат: True
   Приоритет: Средний
   Исправлено: Нет

4. Баг №004: Метод is_empty() обрабатывает только пробелы
   Описание: Метод не обрабатывает другие whitespace символы (\t, \n)
   Шаги воспроизведения:
     1. Вызвать utils.is_empty("\t\n")
   Ожидаемый результат: True
   Фактический результат: Зависит от реализации
   Приоритет: Средний
   Исправлено: Да (используем strip() вместо проверки пробелов)

Рекомендации:
1. Добавить обработку нестроковых входных данных
2. Добавить больше документации для edge cases
3. Рассмотреть возможность создания констант для часто используемых разделителей
